# Semáforo Inteligente com Arduino
Projeto desenvolvido para estudar sistemas embarcados utilizando Arduino e praticar o armazenamento de programação no Github.

## Componentes
- Arduino Uno
- LEDs
- Botão
- Resistores (220 Ohms para as LEDs e 10 kOhms para o botão)

## Funcionalidades
- Controle de veículos
- Controle de pedestres
- Temporização usando millis()
- Comunicação Serial
